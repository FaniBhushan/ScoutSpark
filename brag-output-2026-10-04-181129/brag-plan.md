# Brag Plan: ScoutSpark

## What is this app?
ScoutSpark helps students find and assess capstone project ideas using role-specialized discovery, research, rubric evaluation, and evidence checks.

## The angle
A capstone idea should survive more than a brainstorm. Show ScoutSpark taking a structured request through a reviewed plan and into ranked scorecards, while the offline demo label stays visible so nobody mistakes synthetic records for live evidence.

## Hook (first 2-3 seconds)
A capstone prompt lands on screen: “One project idea. Several checks.” Then the ScoutSpark configuration UI snaps into view.

## Key moments (the middle)
- Choose Offline demo and a synthetic fixture, with the synthetic-data notice clearly visible.
- Preview and validate configuration before research starts; show the resolved search and rubric.
- Reveal ranked finalist cards with weighted scores, evidence, and a visible gate caveat.

## Outro / punchline
“Good ideas get reviewed.” End on ScoutSpark and the real UI caption: “Review the source plan and scoring weights before starting research.”

## User flow worth showing
Choose offline demo and structured request → preview and validate the plan → start research → inspect ranked scorecards, evidence, and gate caveats.

- Preset: polished
- Creative direction: a calm, confident product film for careful capstone planning
- Interpretation: Use crisp UI movement and clear holds; keep claims grounded and show the synthetic-data caveat in the demo scene.
