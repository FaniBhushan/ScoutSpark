ScoutSpark limited preview

# GitHub release notes

ScoutSpark is a local research agent that helps students explore capstone
project ideas that fit their interests, skills, time, and resources.

## What’s included

- Search for project ideas using your own API keys.
- Compare ideas with scores, sources, and warnings.
- Generate a detailed proposal when evidence checks pass, or request a clearly marked exploratory proposal.
- Try an offline demo with synthetic examples before configuring live services.

## Getting started

Follow the [README setup guide](https://github.com/FaniBhushan/SparkScout) to run
ScoutSpark locally. Live research uses your own OpenAI and Tavily API keys. Keep
those keys private and review provider costs before running live searches.

## Preview limitations

This is an early preview, not the completed V2 release milestone. Results can be
incomplete or unverified, and a scored idea does not mean its proposal is
verified. In the saved offline check, ScoutSpark missed the requested candidate
count in all ten runs. One recorded live pilot produced no verified proposals;
a couple of later live runs were acceptable but are not part of the saved
evaluation sample. Read the [limited preview notes](https://github.com/FaniBhushan/SparkScout/blob/main/docs/v2-limited-preview-2026-10-08.md)
and [release check](https://github.com/FaniBhushan/SparkScout/blob/main/docs/v2-release-check-2026-10-08.md)
for details.

Please check sources and warnings before relying on an idea. Feedback and bug
reports are welcome through [GitHub Issues](https://github.com/FaniBhushan/SparkScout/issues/new/choose).
Do not include API keys, personal data, or private documents in public issues.
